# Виправлення змішування даних — 21 вересня 2026

## Що вже застосовано на mydovira.com

Виправлено імпорт Top20 і Google Maps:

- Спільний телефон або сайт більше не є підставою об'єднання компаній.
- Без збереженого ідентифікатора джерела потрібні однакова нормалізована назва, місто й адреса та рівно один кандидат. Нечіткий збіг назви/прізвища не використовується.
- Навіть з відомим джерелом невідповідність назви/міста блокує оновлення. У Top20 також блокуються конфліктні історичні джерела одного профілю.
- Звичайний імпорт не перезаписує вже заповнену назву. Джерело не можна переприв'язати до іншого профілю або видалити в нього як «дублікат».
- Нові відгуки Top20 зберігають справжній тип джерела й URL з ідентифікатором відгуку. Старі посилання більше не стираються. Історичний простір хешів залишено для повторного імпорту без дублікатів.
- Імпорт тільки відгуків виконується в транзакції з перевіркою джерела до запису відгуків.
- Контакти з JavaScript-масиву адрес фільтруються за компанією сторінки: сторонні компанії з того ж HTML не додаються до її контактів.

Нові неоднозначні записи можуть створюватися окремо, а перейменування компанії потребує перевірки. Це свідомий компроміс: автоматичне злиття має бути підтвердженим.

## Межі відновлення старих даних

Старий імпорт стирав URL відгуків. Перевірка збережених хешів проти базових URL 37 профілів не відновила однозначної атрибуції; хеші могли включати вже втрачені фрагменти з ID відгуків. Прямий запит до Top20 під час роботи повернув 403. Тому переносити старі відгуки за припущенням небезпечно.

Для завершення відновлення потрібні дані окремих компаній із підтверджених джерел або початкові імпортні файли/резервні копії. Локальний SQL-дамп від 2 липня містить, зокрема, профілі 1044 і 1052, але є історичним, а не підтвердженням актуальних контактів; його не застосовано поверх сучасної бази.

Порядок відновлення: визначити бізнес для кожного source URL → відновити/створити окремі профілі → переносити тільки достовірно зіставлені відгуки → перерахувати рейтинги → перевірити опис, досьє, контакти й категорії → зняти позначку та опублікувати. Невизначені відгуки залишаються непублічними разом із чернеткою.

Перевіряти відповідність одній компанії, змістовний опис послуг, актуальні контакти/географію, належність відгуків, відсутність дублікатів, canonical, robots і sitemap. Аналізувати фактичну індексацію та покази в Search Console протягом наступних 4–6 тижнів; це період спостереження, а не гарантія зростання.
