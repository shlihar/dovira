# Правило «відгуки АБО контакти АБО досьє» — застосовано 21.09.2026

За прямою вказівкою користувача відкрито всі публічні профілі, що мають принаймні одну ознаку:

- хоча б один фактично опублікований відгук будь-якого джерела;
- непорожній телефон, email, сайт або адресу;
- непорожнє досьє.

Режим: `seo.profile_indexing_mode = reviews_contacts_dossier`. Старі strict-критерії та список 2 902 ID більше не обмежують цей режим. Саме місто, довгий опис, оцінка/вердикт без тексту досьє, AI-аналіз чи старий лічильник відгуків самі по собі не відкривають профіль.

Активність, публікація, видимість у каталозі та відсутність `[IDENTITY_REPAIR_REVIEW]` обов'язкові. HTML без тексту, пробіли та нерозривні пробіли не є досьє. Наявність контактного поля тут є критерієм відкриття, не перевіркою достовірності цього контакту.
