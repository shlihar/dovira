# Усі публічні профілі відкриті для індексації

21 вересня 2026, за прямою вказівкою користувача прибрано вимоги до відгуків, контактів і досьє. Режим `seo.profile_indexing_mode = all_public` дозволяє індексацію всіх активних, опублікованих і видимих у каталозі профілів. Чернетки, приховані та записи з маркером карантину не публікуються цією зміною.

Спільна перевірка `ProfileSeoIndexPolicy::isPublic()` використовується сторінками профілів та sitemap. Зміна режиму автоматично оновлює кеш sitemap через наявний ключ політики. Старі режими збережено для контрольованого відкату.

Результат на сервері: **34 228 URL** у sitemap, без дублів, пропущених або зайвих URL відносно попереднього повного списку плюс чотири щойно відкриті профілі. `sitemap-profiles-1.xml`: HTTP 200, валідний XML, 7 038 036 байтів. Усі чотири раніше порожні профілі та «Колиба Забава» перевірені через HTTP: 200, `index, follow`, немає X-Robots-Tag. Контрольний карантинний профіль повертає 404.

Перевірки: 57 тестів, 218 тверджень — успішно. Серед них перемикання політики з уже заповненим кешем sitemap, відкриття порожніх профілів і збереження меж публікації.

Розгорнуто лише чотири файли: `config/seo.php`, `app/Support/ProfileSeoIndexPolicy.php`, `app/Http/Controllers/CatalogPageController.php`, `app/Http/Controllers/SeoController.php`. Перед заміною перевірено хеші поточних файлів, створено резервну копію, перевірено PHP-синтаксис; після заміни перебудовано config cache.
