# Імпорт адвокатів з uadvokat.com.ua

## Як це працює

```
uadvokat.com.ua (реєстр ЄРАУ)
        │  збір: місто → сторінки page-N → картки адвокатів
        ▼
УСІ адвокати → профілі DOVIRA (ПІБ, телефон, email, адреса, категорія)
        │  безкоштовно, без AI
        ▼
Авто-відбір «валідних» (у кого є цифровий слід):
  1. Індекс top20.ua міста (тег advokat + категорія адвокатів + тег yurist)
     · персональний збіг (прізвище+ім'я) → одразу імпорт ВІДГУКІВ з його top20-картки
     · фірмовий збіг («Прізвище і партнери», «бюро Прізвища») → лише сигнал для AI
  2. Email на власному домені → перевірка, чи живий сайт → сайт у профіль + валідний
  3. Google Places: точка на картах з відгуками (працює після увімкнення
     Places API (New) в Google Cloud Console; вмикається автоматично)
        ▼
Валідні → AI-збагачення (опис, seo, пошук офіційного сайту й відгуків).
Контакти з офіційного сайту ПЕРЕКРИВАЮТЬ реєстрові (телефон завжди, email якщо порожній).
Невалідні → лишаються довідковими картками; AI можна запустити пізніше вибірково.
```

## Запуск з адмінки

Сторінка **AI збагачення профілів** → кнопка **«Імпорт адвокатів (uadvokat)»**:

| Поле | Що означає |
|---|---|
| Посилання на місто | `https://uadvokat.com.ua/reestr/{область}/{місто}/` — скопіювати з сайту |
| З якої / по яку сторінку | ~10 адвокатів на сторінці; порожньо = все місто |
| Макс. адвокатів | запобіжник для тестових запусків |
| Лише одноосібники | фільтр «Індивідуальна адвокатська діяльність» |
| Одразу публікувати | вимкнено → чернетки на ручну перевірку |
| AI-збагачення | **Лише валідні** (рекомендовано) / Без AI / Для всіх |

Прогрес видно у тому ж журналі: batch зі статусом `collecting` (йде збір) →
`queued/processing` (AI) → `completed`. Кількість зібраного/відібраного — в назві batch-а.

## Запуск з консолі

```bash
# тест без запису
php artisan dovira:import-uadvokat odesa odesa --end-page=2 --dry-run

# місто повністю: всі профілі + AI лише валідним + одразу публікувати
php artisan dovira:import-uadvokat odesa odesa --publish --ai-mode=valid

# порціями по сторінках
php artisan dovira:import-uadvokat kiev kiiv --start-page=1 --end-page=50 --publish
```

Опції: `--ai-mode=none|valid|all`, `--solo-only`, `--publish`, `--max-lawyers=`, `--dry-run`.
Слаги міст/областей — з URL на uadvokat.com.ua/reestr/.

## Вибіркове AI вручну

Список **Профілі** → відмітити чекбоксами → bulk-дія **«AI-збагачення вибраних»**.
Створює batch і збагачує лише вибрані (незалежно від того, звідки профіль).

## Передумови

- На хостингу мають бути актуальні файли (див. список у git) і після заливки —
  `php artisan queue:restart`. Черга СПІЛЬНА між локальною машиною і хостингом
  (одна MySQL): якщо на хостингу старий код, він перехоплює job-и і ламає нові фічі.
- Google Places для ширшого відбору: Google Cloud Console → увімкнути
  **Places API (New)** для ключа `GOOGLE_MAPS_API_KEY`. Код підхопить сам.
- Вартість: AI ≈ лише для ~10% адвокатів (валідних). Решта — безкоштовно.
